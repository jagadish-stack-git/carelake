A FHIR lakehouse that forgets who you are before it remembers anything else.

HL7 FHIR R4 bundles for synthetic patients, checked against JSON Schema at the door, scrubbed to HIPAA Safe Harbor before the curated layer exists, modelled as a Kimball star on DuckDB, shipped to Azure Data Lake Storage. Every number below is read from status.json, written by the pipeline itself.
